# cdop:crediting-program

Served at `/rels/crediting-program`.

**Meaning.** From a project to its crediting-program facet: the program, the standard with its exact CDOP name, the initial and current standard versions, and links to the reference lists.

**Target.** `/v2/projects/{id}/crediting-program`, a singleton facet resource.

**Cardinality.** Exactly one on a project.

**Example.**

```json
"cdop:crediting-program": { "href": "https://cdop.rethinkcarbon.co.uk/v2/projects/prj_01K5N8X2Q7R3V4W5Y6Z7A8B9C0/crediting-program" }
```

**Availability.** M1.
