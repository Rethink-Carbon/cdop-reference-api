# cdop:cobenefits

Served at `/rels/cobenefits`.

**Meaning.** From a project to its co-benefits facet: SDGs, assessment methods, targets and reported impacts.

**Target.** `/v2/projects/{id}/cobenefits`, a singleton facet resource.

**Cardinality.** Exactly one on a project.

**Example.**

```json
"cdop:cobenefits": { "href": "https://cdop.rethinkcarbon.co.uk/v2/projects/prj_01K5N8X2Q7R3V4W5Y6Z7A8B9C0/cobenefits" }
```

**Availability.** Route M1; seeded data arrives in M3.
