# cdop:issuance

Served at `/rels/issuance`.

**Meaning.** From a unit block to the issuance batch that created it.

**Target.** `/v2/issuances/{id}`.

**Cardinality.** Exactly one on a unit block.

**Example.**

```json
"cdop:issuance": { "href": "https://cdop.rethinkcarbon.co.uk/v2/issuances/iss_01K5N8X2Q7R3V4W5Y6Z7A8B9E2" }
```

**Availability.** M1.
