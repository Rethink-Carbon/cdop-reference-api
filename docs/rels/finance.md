# cdop:finance

Served at `/rels/finance`.

**Meaning.** From a project to its finance facet: expected costs and revenue, funding required and secured, financing options, community benefit mechanisms, the declaring entity, expected and realised credit prices.

**Target.** `/v2/projects/{id}/finance`, a singleton facet resource.

**Cardinality.** Exactly one on a project.

**Example.**

```json
"cdop:finance": { "href": "https://cdop.rethinkcarbon.co.uk/v2/projects/prj_01K5N8X2Q7R3V4W5Y6Z7A8B9C0/finance" }
```

**Availability.** M1.
