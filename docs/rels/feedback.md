# cdop:feedback

Served at `/rels/feedback`.

**Meaning.** From the root to the schema-feedback register: every numbered `CDOP-FB-nnn` entry with its category, evidence, impact, what the API does and the proposal.

**Target.** `/rels/feedback`, which renders `SCHEMA-FEEDBACK.md`. The same content is the MCP resource `cdop://feedback`.

**Cardinality.** Exactly one on the root.

**Example.**

```json
"cdop:feedback": { "href": "https://cdop.rethinkcarbon.co.uk/rels/feedback" }
```

**Availability.** M1.
