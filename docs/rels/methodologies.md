# cdop:methodologies

Served at `/rels/methodologies`.

**Meaning.** From a project to the methodologies it applies, each with its versions and document links.

**Target.** `/v2/projects/{id}/methodologies`, a HAL collection.

**Cardinality.** Exactly one on a project.

**Example.**

```json
"cdop:methodologies": { "href": "https://cdop.rethinkcarbon.co.uk/v2/projects/prj_01K5N8X2Q7R3V4W5Y6Z7A8B9C0/methodologies" }
```

**Availability.** M1.
