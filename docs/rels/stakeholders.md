# cdop:stakeholders

Served at `/rels/stakeholders`.

**Meaning.** From a project to its stakeholders facet: the primary developer, the other stakeholders with their roles, the organisations behind them, and the list of landowners.

**Target.** `/v2/projects/{id}/stakeholders`, a singleton facet resource.

**Cardinality.** Exactly one on a project.

**Example.**

```json
"cdop:stakeholders": { "href": "https://cdop.rethinkcarbon.co.uk/v2/projects/prj_01K5N8X2Q7R3V4W5Y6Z7A8B9C0/stakeholders" }
```

**Availability.** M1.
